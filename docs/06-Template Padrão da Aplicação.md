# Template Padrão da Aplicação

### Projeto de Interface - Modelo Padrão

### Estrutura Base (Layout)
A aplicação utiliza um modelo de layout centralizado através do arquivo `_Layout.cshtml`, garantindo que todas as páginas mantenham a mesma identidade visual e navegação. A estrutura é composta por um cabeçalho fixo (Navbar), área de conteúdo dinâmico e rodapé.

### Identidade Visual e Estilização
*   **Cores e Temas:** Suporte nativo a Tema Claro e Tema Escuro.
*   **Framework CSS:** Utilização do Bootstrap 5 para garantir componentes padronizados.
*   **Responsividade:** Design adaptável para dispositivos móveis e desktops.
